
Study Notes: GitHub Repository Basics

1. What is a GitHub Repository?

A repository (repo) is a folder that contains your project's files and their revision history.

Repos can be public (open to everyone) or private (restricted access).


2. Key Concepts

Git: Version control system tracking changes to files.

GitHub: Platform hosting Git repositories online.


3. Common Repo Components

README.md: Project description and setup instructions.

.gitignore: Specifies files to ignore in version control.

LICENSE: Legal license for the project.

src/, docs/, tests/: Common directories for source code, documentation, and testing.


4. Basic Git Commands

git clone <URL>: Copy a repo to your machine.

git status: See changes made to files.

git add <file>: Stage changes for commit.

git commit -m "message": Save changes with a message.

git push: Upload changes to GitHub.

git pull: Download changes from GitHub.


5. Branching

main or master: Default development branch.

git checkout -b <branch-name>: Create and switch to a new branch.

git merge <branch>: Merge changes from another branch.


6. Collaboration Tools

Fork: Copy a repo to your account for independent changes.

Pull Request (PR): Propose changes from one branch or fork into another.

Issues: Report bugs or suggest features.

Actions: Automate workflows like testing and deployment.


7. Best Practices

Write clear commit messages.

Use branches for new features or bug fixes.

Keep the main branch stable.

Review and test code before merging.
